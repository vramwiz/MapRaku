# ちずらく（MapRaku）

道路・線路・文字・記号を組み合わせて案内図を作るWindows用アプリです。現在は初期開発版です。

## 起動

Win64/Release/MapRaku.exeを実行します。同じフォルダーにsk4d.dllが必要です。開発用はWin64/Debug/MapRaku.exeです。

## 地図の作成

左の地図パネルは、上段で道路・線路・水系・記号の分類を選び、その下のサムネイルから配置形状を選びます。道路・JR・私鉄・川は直線、鋭角の連続線、ベジェ曲線の連続線を選択できます。池は円、四角、角丸、閉じたパスなどを通常図形と同じ操作で配置します。線の太さは右上の数値欄とスライダー、線端は「詳細」で調整します。連続線はダブルクリックまたは右クリックで確定すると選択モードへ戻ります。

道路・線路・川は通常の独立レイヤーとして追加されます。編集画面またはレイヤー一覧の右クリックメニューから「高さの区切りを追加」を選ぶと、高さの区間を分けられます。区切りと次の区切りの間を同じ高さとして扱い、同じ区間の道路同士は交差部を接続します。区切りを挟んだ道路同士は立体交差として描画します。グループは整理用であり、高さの指定には使いません。

| 操作 | 動作 |
|---|---|
| 選択モードで空白を左ドラッグ | 範囲選択 |
| 中央ボタンをドラッグ | キャンバス移動 |
| マウスホイール | 拡大・縮小 |
| Altを押す | スナップを一時解除 |
| グループをクリック | 全体選択 |
| グループをダブルクリック | 内部編集 |
| 地図経路または単一経路の地図層を選択して頂点をドラッグ | 点を移動 |
| 編集中の経路の線分をクリック | 点を追加 |
| 頂点を右クリック | 点を削除（最低2点） |
| 選んだ頂点でP | 鋭角／ベジェを切替 |

分類で「記号」を選び、下段で種類を選んでから地図上をクリックします。追加ボタンはありません。駅、信号、横断歩道、歩道橋、番号、駐車場、方位、道路番号、矢印を用意しています。池は水系分類から配置します。通常の図形・文字の組み合わせなので内部も編集できます。基本図形、文字、画像配置は既存の編集ツールを使います。

白／黒の配色は「キャンバスの設定」で解像度と一緒に選択します。切替はキャンバスと道路・線路・一部の文字色へ反映し、記号の固定色は保持します。

## 保存・出力

ファイルメニューから開く、保存、SVG出力、PNG出力を行えます。Ctrl+Oで開く、Ctrl+Sで保存します。編集データは.mapraku形式のJSONです。

画像は外部ファイルを参照するため、元画像も一緒に管理してください。保存時は地図ファイルからの相対パスを使用します。SVGは共通の描画処理で出力し、文字をパス化します。

Release版は未保存変更がある状態で終了すると保存を確認します。Debug版は反復テストのため、終了時の保存確認を出しません。必要な地図は終了前に保存してください。Debug版でも新規作成／ファイルを開く際の変更確認は残します。

## 現在の制限

記号の自動位置合わせや暗色背景での見やすさは調整中です。橋・トンネル専用記号、縦書き、最近使ったファイルは未実装です。外部画像の移動・欠落処理、複雑なグループ変換や効果を含むSVGについては、追加の検証が必要です。

ビルド・検証方法と残作業は[note.md](note.md)、製品仕様は[仕様検討まとめ](ちずらく_仕様検討まとめ.md)を参照してください。
