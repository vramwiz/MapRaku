# ちずらく（MapRaku）

道路・線路・文字・記号を組み合わせて案内図を作るWindows用アプリです。現在は初期開発版です。

## 起動

Win64/Release/MapRaku.exeを実行します。同じフォルダーにsk4d.dllが必要です。開発用はWin64/Debug/MapRaku.exeです。

AviUtl2向けの **SYNC → 地図** プラグインも追加しています。単独版と編集UIを共用し、編集画面は右上の×で閉じると内容をホストへ反映します。ビルド・配置方法と検証範囲は [プラグインの説明](Docs/PLUGIN.md) を参照してください。

## 地図の作成

左の配置パネルは、先頭の「すべて」で全候補を分類ごとに表示します。道路・線路・水系・記号・歩道・建物・図形・文字・その他へ絞り込むこともできます。起動時と分類変更時には表示中の先頭候補が自動で配置対象になります。分類を切り替えると描画途中の前の配置は終了します。独立した選択ツールはなく、右クリックで配置を解除するとクリック選択や編集ができます。道路・JR・私鉄・川は直線、鋭角の連続線、ベジェ曲線の連続線を選択できます。池は円、四角、角丸、閉じたパスなどを通常図形と同じ操作で配置します。線の太さは右上の数値欄とスライダー、線端は「詳細」、色は右側の属性パネルで調整します。道路・線路・川の連続線はダブルクリックで1本を確定して同じ配置を続けます。右クリックは点数が足りれば確定し、足りなければキャンセルして配置を解除します。解除後は最後に配置したものを選択します。

道路・線路・川は通常の独立レイヤーとして追加されます。編集画面またはレイヤー一覧の右クリックメニューから「高さの区切りを追加」を選ぶと、高さの区間を分けられます。区切りと次の区切りの間を同じ高さとして扱い、同じ区間の道路同士は交差部を接続します。区切りを挟んだ道路同士は立体交差として描画します。グループは整理用であり、高さの指定には使いません。

道路・線路・川などの経路を2本選択すると、右クリックの「交差部分」から通常交差、踏切、高架、橋、跨線橋、アンダーパス、トンネル、表現なしを指定できます。「選択1を上にする」「選択2を上にする」で上下関係を、「表現範囲：短い／標準／長い」で記号の範囲を変更できます。交差表示は経路の移動や頂点編集へ追従します。同じ上側経路の橋が重なる、または端同士が近づく場合は、側線を一続きにして途中の端の開きを省きます。離すと別々の橋へ戻ります。画面、PNG、SVGへ同じ表現を出力します。

立体交差では、下側の道路・線路を橋やトンネルの区間で明確に途切れさせます。道路が上なら線路が途切れ、線路が上なら道路が途切れます。透明背景や黒地図でも同じです。通常の道路交差は接続し、踏切には立体交差の切れ目を付けません。

「ルート」分類で経路と開始点・終了点を配置すると、Spaceで10秒の移動プレビューを確認できます。AviUtl2では進行済みの軌跡、移動マーカー、方向ポインターと追従スクロールを使えます。ルートを通行先と同じ高さへ配置すると、高架下では道路と同じ交差範囲・余白で、既定ではマーカーと軌跡が隠れます。マーカー透明度は通常／道路の下の2項目（0＝不透明、100＝完全透明）で、初期値は通常0・道路の下100です。

「歩道」分類には再利用可能な「階段 上り」「階段 下り」と「歩道橋」があります。階段は始点と終点の2点で配置し、線の方向が階段の方向、線幅が階段幅、線の長さが階段長になります。段数は長さに応じた自動調整のほか、右クリックの「階段の段数」から6・10・16段を選択できます。歩道橋も2点で配置し、始点側階段・橋本体・終点側階段の編集可能な3要素として生成します。

| 操作 | 動作 |
|---|---|
| 配置対象がない状態で空白を左ドラッグ | 範囲選択 |
| 未選択のオブジェクトを右クリック | 選択のみ |
| 選択済みのオブジェクトを右クリック | メニュー表示 |
| 中央ボタンをドラッグ | キャンバス移動 |
| マウスホイール | 拡大・縮小 |
| Altを押す | スナップを一時解除 |
| グループをクリック | 全体選択 |
| グループをダブルクリック | 内部編集 |
| 地図経路または単一経路の地図層を選択して頂点をドラッグ | 点を移動 |
| 地図経路の線分を右クリック | メニューの「頂点」から点を追加 |
| 地図経路の頂点を右クリック | メニューの「頂点」から点を削除（最低2点） |
| 選んだ頂点でP | 鋭角／ベジェを切替 |

道路・線路・川は、配置中または端点をドラッグしたときに、同じ系列の経路の端点へ優先して吸着します。JRと私鉄は線路系列として接続できます。直線とベジェ曲線をつなぐと曲線側の端点角度を自動調整し、滑らかにつながるようにします。曲線同士は操作側を調整します。相手側を含めた変更は一回のUndoで戻せます。Altで吸着と角度調整を解除できます。接続後も別々の経路として編集できます。

分類で「記号」を選び、下段で種類を選んでから地図上をクリックします。追加ボタンはありません。駅、信号、横断歩道、歩道橋、番号、駐車場、方位、道路番号、矢印を用意しています。一覧には配置される記号を実際の描画処理で縮小表示します。池は水系分類から配置します。通常の図形・文字の組み合わせなので内部も編集できます。基本図形と文字は左の分類パネルから配置します。

白／黒の配色は「キャンバスの設定」で解像度と一緒に選択します。切替はキャンバスと道路・線路・一部の文字色へ反映し、記号の固定色は保持します。

## 保存・出力

ファイルメニューには新規、開く、上書き保存、名前を付けて保存、最近使ったファイル、データの出力があります。ショートカットは順にCtrl+N、Ctrl+O、Ctrl+S、Ctrl+Shift+S、出力はCtrl+Eです。履歴は開く・保存に成功した地図を新しい順に最大10件記録し、履歴から開いた地図を先頭へ移します。編集データは.mapraku形式のJSONです。データの出力はSVGが初期値で、保存ダイアログのファイル種類からPNGも選べます。

画像は外部ファイルを参照するため、元画像も一緒に管理してください。保存時は地図ファイルからの相対パスを使用します。SVGは共通の描画処理で出力し、文字をパス化します。

Release版は未保存変更がある状態で終了すると保存を確認します。Debug版は反復テストのため、終了時の保存確認を出しません。必要な地図は終了前に保存してください。Debug版でも新規作成／ファイルを開く際の変更確認は残します。

## AIとの連携

Codex等からNamed Pipe経由で、道路・線路・川・主要施設・記号・文字を配置し、部分修正やプレビュー確認ができます。元画像は作成前に角度・方角・範囲を固定して登録します。指示・編集データ・画像はすべてパイプで受け渡します。道路・線路の形状と接続を優先して生成し、細部は人が調整する運用です。

接続手順と対応操作は [AIパイプ連携](Docs/AI_PIPE.md) を参照してください。現在は配置・通信のサンプル検証まで完了しており、実地図画像からの読み取り精度は今後の検証対象です。

## 現在の制限

記号の自動位置合わせや暗色背景での見やすさは調整中です。交差関係とは独立して配置する橋・トンネル専用記号と縦書きは未実装です。外部画像の移動・欠落処理、複雑なグループ変換や効果を含むSVGについては、追加の検証が必要です。

ビルド・検証方法と残作業は[note.md](note.md)、製品仕様は[仕様検討まとめ](ちずらく_仕様検討まとめ.md)を参照してください。
