# 池袋ニコニコ本社・簡略案内図

1920×1080。左半分をサムネイルの文字用に空け、右側に地図を配置。
JR線を水平にし、北を右、東を下にした概略図。道路の曲がり角・距離・建物の大きさは読みやすく調整しており、測量図や厳密な徒歩経路図ではない。

池袋駅、PARCO本館、P’PARCOの位置関係と、明治通り・施設前の道路・ウイロードを抽出。ウイロードとJR線には立体交差を設定。目的地は営業当時のニコニコ本社（P’PARCO B1F/B2F）を示す。

参照資料（2026-09-20確認）:

- PARCO公式周辺図: https://ikebukuro.parco.jp/assets/images/info/map.png
- PARCO公式アクセス案内: https://ikebukuro.parco.jp/info/
- ドワンゴ公式・当時の所在地: https://dwango.co.jp/news/5761241986112766700/

公式地図の画像自体は成果物に埋め込まず、必要な位置関係を編集可能な道路・線路・建物・文字で作図した。`.mapraku`が編集用ファイル、`final.png`が表示用プレビュー。開いているAviUtl2プラグインの編集文書へも反映済み。
